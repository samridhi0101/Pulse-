Welcome to Pulse v2.0

Pulse is Nalashaa's operational intelligence platform — real-time dashboards across Engineering, Sales, HR, Talent Acquisition, PMO, and Finance, with the President's-eye view on Org Pulse.

Drill-down pattern. Every metric is clickable. Clicks open a right-panel flyout with detail, never a new browser tab. Three drill-down levels: Org → Dept → Record.

Themes. Top-right pill toggle switches between Classic/Modern (visual style) and Light/Dark (luminance). Your preference persists across sessions.

Quick navigation. Press Cmd+K (or Ctrl+K on Windows) to open the command palette — fastest path to any page, metric, or command.

5-minute Tour

1. Land on Org Pulse — see compact dept cards with RAG status. Click any card to drill into that dashboard.

2. Read the Claude Daily Brief at the top — AI-summarized priorities for the day.

3. Use the bell icon for alerts; click an alert to jump to the breached KPI.

4. Try the KPI Threshold Manager — drag handles to set RAG breakpoints. Section background tints reflect the current band.

5. Configure your AI endpoint in Settings → AI & Endpoints. Default is http://localhost:8080/v1/brief.

Glossary — All KPIs & Terms

P360 — Composite Score
A 6-dimension project health score (Discipline · Quality · Communication · Risk · Stakeholder Trust · Velocity), each scored 0-10. Composite under 6.0 = Red.
Golden Ratio
Ratio of billable to non-billable headcount. Higher = leaner overhead. Target ≥ 1:7.
Mining Threads
Active deliverables aimed at expanding existing accounts (cross-sell, upsell, scope expansion).
Account Escalation
A formally raised concern from a client or internal stakeholder requiring DM action. Color-coded by severity (Critical / High / Medium / Low).
BOFU
Bottom-of-Funnel — the closing stage of a sales deal. BOFU duration = avg days a deal spends in this stage.
TOFU
Top-of-Funnel — newly captured leads not yet qualified.
Sprint Velocity
Story points completed per sprint. Trend across last 4 sprints indicates team health.
Slip-through Rate
% of new hires who exit within 90 days of joining. Lower is better.
YTD Billing Forecast
Year-to-date billed revenue against plan. Computed nightly from Tally + project actuals.
RAG
Red / Amber / Green — universal status convention. Red = breach requiring action; Amber = warning; Green = on track.
SOW
Statement of Work — contract artifact defining scope, timeline, and commercials for an engagement.
DM
Delivery Manager — owns 4-8 client projects; first line of accountability for project health.

Frequently Asked Questions

Q: How often does data refresh?

By default, every 5 minutes. You can change this in Settings → Data & Refresh. Some sources (Finance) sync nightly.

Q: How do I export a page for the board?

Click the Export icon in the top-right of any page. Choose PDF for board pack, Excel for raw data. Or press Ctrl+P for print-quality.

Q: Why don't I see the Admin tab?

Admin Console is restricted to users with the Admin role. Contact your Pulse administrator to elevate access.

Q: Can I save a custom view?

Yes — every dashboard supports Saved Views. Configure filters and date range, then click "Save view" in the page header. Manage saved views in Settings → Saved Views.

Q: What's the difference between Classic and Modern?

Classic preserves the v1 visual identity (Sky Blue accent, flat cards). Modern adds frosted-glass cards, deeper Pulse Orange (#E65100), and a Teal accent (#14B8A6) for info states. Functionality identical.

Troubleshooting

Dashboard shows "Data unavailable"

One of your source systems is unreachable. Check Admin → Integrations for connection status. The dashboard will continue to show last known values until the source comes back.

Theme toggle not persisting

Pulse uses localStorage to remember your theme choice. If you're in Incognito/Private browsing, preferences won't persist. Switch to a regular window for persistence.

Daily Brief is generic / placeholder

The Claude AI endpoint is not yet configured. Go to Settings → AI & Endpoints and set your endpoint URL plus API key. Default development endpoint: http://localhost:8080/v1/brief.

Cmd+K not working

Some browser extensions intercept Cmd+K (e.g., bookmark managers). Try Ctrl+K instead, or click the search icon in the top navigation.
